# Go LeetCode 常用数据结构实现

刷 LeetCode 时，经常会遇到优先队列、单调队列这类“题目里经常用到，但标准库不会直接替你封装好全部细节”的数据结构。  
Go 的做法很有代表性：标准库提供维护堆结构的能力，但底层存储和比较规则需要我们自己实现。

## 优先队列

Go 标准库里没有直接叫“优先队列”的类型，一般使用 `container/heap` 来实现。  
它的核心思路是：`heap` 包负责维护堆序，而我们负责告诉它“元素怎么比较”“底层容器怎么增删”。

### `sort.Interface` 和 `heap.Interface` 的关系

`heap.Interface` 本身并不是一个完全独立的接口，它是在 `sort.Interface` 的基础上扩展出来的：

```go
type Interface interface {
	sort.Interface
	Push(x any)
	Pop() any
}
```

这里可以拆成两部分理解：

- `sort.Interface` 提供 `Len`、`Less`、`Swap` 三个方法。
- `heap.Interface` 在此基础上再补上 `Push` 和 `Pop`。

为什么堆要依赖 `sort.Interface`？因为维护堆本质上也离不开“比较”和“交换”：

- `Len()` 告诉 `heap` 当前有多少个元素。
- `Less(i, j)` 决定谁的优先级更高。
- `Swap(i, j)` 让 `heap` 在上浮、下沉时能够交换元素位置。

也就是说，`heap` 包并不关心你的元素到底是 `int`、结构体，还是别的类型；它只关心这几个行为是否已经提供。  
只要你把“长度、比较、交换、增删”这几件事实现好，`heap` 就能帮你把这个容器维护成一个优先队列。

### 一个最小堆的实现

下面是一个最常见的 `int` 最小堆写法：

```go
package main

import (
	"container/heap"
	"fmt"
)

type IntHeap []int

func (h IntHeap) Len() int           { return len(h) }
func (h IntHeap) Less(i, j int) bool { return h[i] < h[j] } // 值越小，优先级越高
func (h IntHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }

func (h *IntHeap) Push(x any) {
	*h = append(*h, x.(int))
}

func (h *IntHeap) Pop() any {
	old := *h
	x := old[len(old)-1]
	*h = old[:len(old)-1]
	return x
}

func main() {
	h := &IntHeap{3, 1, 2}
	heap.Init(h)

	heap.Push(h, 0)
	fmt.Println(heap.Pop(h)) // 0
	fmt.Println(heap.Pop(h)) // 1
	fmt.Println(heap.Pop(h)) // 2
	fmt.Println(heap.Pop(h)) // 3
}
```

这段代码里，每个方法的职责其实很明确：

- `Len`、`Less`、`Swap` 实现的是 `sort.Interface`。
- `Push`、`Pop` 实现的是 `heap.Interface` 新增的部分。
- `heap.Init(h)` 会把一个普通切片原地调整成堆。
- `heap.Push(h, x)` 会先调用你写的 `Push` 把元素放到底层容器末尾，再通过上浮操作恢复堆序。
- `heap.Pop(h)` 会先把堆顶元素换到末尾，再通过下沉调整堆，最后调用你写的 `Pop` 把末尾元素取出来。

这里有一个很容易忽略的细节：**你自己实现的 `Pop` 为什么是“弹出最后一个元素”，而不是“弹出堆顶元素”？**  
因为真正的堆顶调整工作已经由 `heap.Pop` 做完了。调用到你的 `Pop` 时，优先级最高的元素已经被换到切片末尾，所以这里只需要把最后一个元素删掉并返回即可。

### 为什么 `Push` 和 `Pop` 要用指针接收者

`Push` 和 `Pop` 会直接修改切片长度，因此必须写成指针接收者：

- `Push` 需要 `append`。
- `Pop` 需要重新切片，缩短长度。

而 `Len`、`Less`、`Swap` 不需要改变切片本身的长度，使用值接收者就够了。  
如果你想实现最大堆，也很简单，只需要把比较规则改一下：

```go
func (h IntHeap) Less(i, j int) bool { return h[i] > h[j] }
```

这样堆顶就会变成当前最大的元素。

## 单调队列

单调队列常用于滑动窗口最值问题。  
在大多数题目里，我们只需要“尾部入队、头部出队”，直接用 `slice` 实现就已经足够了；如果你真的需要更灵活的双端操作，再考虑链表或专门的双端队列结构。

```go
package main

import "fmt"

func main() {
	q := []int{}

	// 入队：维护一个单调递减队列，队头始终是当前最大值
	push := func(x int) {
		for len(q) > 0 && q[len(q)-1] < x {
			q = q[:len(q)-1]
		}
		q = append(q, x)
	}

	// 出队：如果离开窗口的值正好在队头，就把它弹出
	pop := func(x int) {
		if len(q) > 0 && q[0] == x {
			q = q[1:]
		}
	}

	front := func() int {
		return q[0]
	}

	push(1)
	push(3)
	push(2)
	fmt.Println(front()) // 3

	pop(3)
	fmt.Println(front()) // 2
}
```

单调队列的关键不在于“把所有元素都存下来”，而在于**把不可能成为答案的元素及时丢掉**。  
因此它特别适合处理“窗口移动时，持续维护最大值/最小值”的问题。
